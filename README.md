# CLI Chatbot

A command-line chatbot built with Python as part of learning the Anthropic API.

## What it does

- Runs entirely in the terminal
- Maintains conversation memory across messages (multi-turn)
- Uses Groq API with llama-3.3-70b-versatile as the LLM backend

## What I learned

- How the Anthropic API works (stateless calls, message structure)
- How to manage conversation history manually to give the model memory
- How to build a multi-turn CLI chatbot from scratch in Python

## Stack

- Python
- Groq API (llama-3.3-70b-versatile)
- Jupyter Notebook

## Context

Built while going through Anthropic's "Building with the Claude API" course as a first-year CS student teaching myself AI development beyond college curriculum.
